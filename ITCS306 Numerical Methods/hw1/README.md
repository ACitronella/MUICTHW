Homework 1

1. Calculate sqrt(N) using Heron's method. 
Using `python heron.py $NUM` or `python heron.py $NUM -sc $SC` 
where 
    $NUM is number to be calculate sqrt(number),
    -sc $SC is stopping criteria (default is 5 * 10^(-1))

2. Convert decimal number base-10 to IEEE-754 bit string. 
Using `python decimal2bitstring.py $DECI` or `python decimal2bitstring.py $DECI -b64`
where
    $DECI is decimal number base-10 to be converted to IEEE-754 bit string (32-bit by default),
    -b64 for 64-bit conversion.

3. Convert IEEE-754 bit string to decimal number.
Using `python bitstring2decimal.py $BSTR`
where
    $BSTR is a bit string to be converted to decimal number. Can be both 32-bit or 64-bit.

Everything work on base python doesn't have to install any dependency
