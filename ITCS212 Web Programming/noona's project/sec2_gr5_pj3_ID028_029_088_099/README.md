<h2>To run MovFlix web application:</h2>
    1. Download sec2_gr5_database.sql and set Users and Privilages according to .env file in the server folder.<br>
    2. Open Terminal, change directory to sec2_gr5_pj3_ID028_029_088_099/server and type <b>npm start</b> to run the server.<br>
    3. Open another Terminal, change directory to sec2_gr5_pj3_ID028_029_088_099/sec2_gr5_src and type <b>npm start</b> to run the client side (React).<br>
    4. Start testing.<br><br>
