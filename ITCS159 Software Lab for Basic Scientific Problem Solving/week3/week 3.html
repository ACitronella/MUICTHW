Exercise 2: Solving Equation¶

If you want to calculate the distance traveled by a falling object, you need to write down the equation of motion. If the initial displacement and velocity are both equal to zero, it boils down to:

\begin{align} s=\frac{1}{2}gt^2 \end{align}

s: Distance or Hight of falling object in meter \begin{align} g:=9.8\frac{m}{s^2} \end{align} t: time in second

Find out time for falling object at 120 meters from HIGHTOWER. Show graph of falling equation intersec x-axis.

In [120]:
from sympy import solve, Symbol
from sympy.plotting import plot
g = 9.8
t = Symbol("t")
s = 1/2 * g * t**2
sn = 120
print(o := solve((s - sn), dict=True))
plot(s, 120, (t, 0, 10))
